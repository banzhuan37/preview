# BioSearch Vision UI 原型

面向 Windows 的果蝇行为定量分析桌面界面原型。当前版本专注于科研工作流、页面结构、图表表达和交互体验，不包含检测算法与后端数据处理。

## 打开方式

- Windows：双击 `启动原型.bat`
- 其他系统：直接打开 `index.html`

## 已设计页面

1. 科研总览：实验进度、轨迹质量、近期项目和快捷任务。
2. 实验项目：检索和管理科研项目；点击项目后填写观察器皿、果蝇数量并启动 AI 分析。
3. 视频导入：创建实验后从本地选择或拖放视频，批量建立导入队列。
4. 轨迹工作台：播放 AI 跟踪视频，展示轨迹置信度、波动方差、ROI 和身份连续性。
5. 运动能力：个体与群体距离、速度差值、转向、兴奋度、休息占比和运动节律。
6. 空间偏好：轨迹密度热图、高活跃区域高亮和主要活动位置总结。
7. 社交行为：个体距离、接近离开、接触、跟随追逐、聚集指数和群体扩散范围。
8. 组间统计：多个实验在多个行为指标上的交叉比较。
9. 数据管理：选择指定实验，导出全部原始视频、轨迹、事件、元数据和分析配置。

## 设计原则

- Windows 桌面式窗口、侧栏和命令栏结构。
- 图表默认显示原始个体点、样本量、置信区间和统计说明。
- 青绿色代表主任务，蓝色代表对照，琥珀色代表刺激，红色代表异常。
- 页面围绕“实验 → AI 跟踪 → 行为分析 → 跨实验统计 → 原始数据导出”科研闭环组织。
- 当前为纯前端交互原型，无第三方依赖，可作为后续 Electron、Tauri、WebView2 或 Qt 前端参考。
